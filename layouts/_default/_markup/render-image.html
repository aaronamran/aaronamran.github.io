{{- /* Render hook for Markdown images: ![alt](src) Priority: 1. Page bundle resource (image co-located with index.md) 2. Global assets/ directory resource 3. Fallback: raw URL passthrough (external URLs or static/ files) Processing: resize to max 1000px wide, convert to WebP at q100 */ -}} {{- $src := .Destination -}} {{- $alt := .Text -}} {{- $title := .Title -}} {{- $img := .Page.Resources.GetMatch $src -}} {{- if not $img -}} {{- $img = resources.Get $src -}} {{- end -}} {{- if $img -}} {{- $processed := $img.Resize "1000x webp q100" -}} {{- else -}} {{- end -}}
